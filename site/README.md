# Awesome RSI — Landing Page

React + Vite single-page site for the awesome-rsi paper collection, deployed to GitHub Pages.

## Develop

```bash
cd site
npm install
npm run dev
```

## Build & deploy

```bash
npm run build    # outputs to site/dist
npm run deploy   # builds and pushes dist/ to the gh-pages branch
```

After the first deploy, enable GitHub Pages in the repo settings (Settings → Pages → Deploy from branch → `gh-pages`), then set the site URL in the repo's "About" section.

## Data

- `src/data/papers.js` — paper list. Metadata fetched from the arXiv API; citation counts from Semantic Scholar (snapshot 2026-08-19). Each entry carries `tags` used by the topic filter.
- `src/data/paperTaxonomy.js` — benchmark taxonomy used by the faceted filters.
- `src/data/citationGraph.js` — corpus-level citation edges generated by `npm run sync:citations`.
- `src/data/resources.js` — books & courses (placeholders for now).
